# v0.3 URL Import + Speaker Tracks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v0.3 so a user can start from a permitted video URL or local file, then produce a dubbed MP4 with speaker-specific voices and subtitle colors.

**Architecture:** Keep the Python processing engine and localhost Web UI. Add a small source-import boundary before `init_project()`, then carry speaker profile metadata through STT segments, TTS synthesis, subtitle overlay rendering, manifests, CLI, and Web UI.

**Tech Stack:** Python stdlib, yt-dlp executable integration, xAI STT/Grok/TTS, FFmpeg/ffprobe, localhost `http.server` UI, pytest.

---

## Scope

v0.3 is not a general-purpose downloader. URL import must be framed as local import of videos the user owns or has permission to use.

In scope:

- Single URL import for a user-provided source URL.
- Local file input remains the default path.
- Rights-confirmation checkbox for URL import in Web UI and explicit CLI flag for URL import.
- Speaker voice mapping for up to three detected speaker labels.
- Speaker subtitle color mapping for burned subtitles and manifests.
- Existing MP4, SRT, VTT outputs remain.

Out of scope:

- Login/session/cookie import.
- Bulk profile, timeline, bookmark, like, or media-tab import.
- DRM, geofence, age-gate, private content, or deleted-content bypass.
- Voice cloning.
- Full timeline editor.
- Automated lip-sync.

```python
from pathlib import Path
from urllib.parse import urlparse


SUPPORTED_URL_SCHEMES = {"http", "https"}


def build_source_import_plan(source_url: str, output_dir: Path, rights_confirmed: bool) -> dict:
    if not rights_confirmed:
        raise ValueError("URL import requires confirmation that you have rights to use this source.")
    parsed = urlparse(source_url)
    if parsed.scheme not in SUPPORTED_URL_SCHEMES or not parsed.netloc:
        raise ValueError("URL import requires an http or https URL.")
    output_template = Path(output_dir) / "source.%(ext)s"
    command = [
        "yt-dlp",
        "--no-playlist",
        "--restrict-filenames",
        "--merge-output-format",
        "mp4",
        "--print",
        "after_move:filepath",
        "-o",
        str(output_template),
        source_url,
    ]
    return {
        "tool": "yt-dlp",
        "command": command,
        "metadata": {
            "source_kind": "url",
            "source_url": source_url,
            "host": parsed.netloc.lower(),
            "rights_confirmed": True,
        },
    }
```
